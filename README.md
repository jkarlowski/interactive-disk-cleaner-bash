# Interactive Disk Space Manager (Bash)

A simple and effective CLI tool to find and manage large files in your home directory.

## Features
- Scans your home directory up to 3 levels deep.
- Lists the largest files in a human-readable format (MB/GB).
- Interactive menu for quick file inspection or deletion.
- Safety confirmation prompt before any file removal.

## How to run
1. Clone the repository: `git clone https://github.com/YOUR-NICK/interactive-disk-cleaner-bash.git`
2. Give execution rights: `chmod +x usuwacz.sh`
3. Run the script: `./usuwacz.sh`

## Built with
- Bash
- Linux Core Utilities (find, sort, numfmt)
